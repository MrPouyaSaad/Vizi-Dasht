## 🚀 About the Project

Vizi Dasht is a Flutter-based seller application developed for the VIZITOM platform.  
The app enables sellers to manage products, receive notifications, and monitor basic performance insights in a smooth and responsive environment.

This project focuses on practical state management using BLoC and real-time communication via Firebase services.

---

## ✨ Features

- 🔔 Push Notifications using Firebase Cloud Messaging (FCM)  
- 📊 Event tracking with Firebase Analytics  
- 📦 Product management interface  
- 🎨 Interactive UI with animations  
- 🧩 BLoC-based state management  
- 📱 Responsive layout for different screen sizes  

---

## 🏗 Architecture

This project uses:

- Feature-based folder structure  
- BLoC / Cubit for state management  
- Service layer abstraction for API calls  
- Firebase integration layer  

```
lib/
 ├── widgets/
 ├── screens/
 │    ├── dashboard/
 │    ├── products/
 │    ├── orders/
 │    └── profile/
 └── main.dart
```
